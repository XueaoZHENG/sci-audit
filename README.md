# sci-audit — SCI 论文数据真实性审查 Skill

一个用于 AI 编程助手（Kimi Code / Claude Code 等）的审查技能：对**生物类 SCI 论文**做系统性的**造假与数据真实性审查**。

## 覆盖范围

- **图像完整性**：凝胶 / Western blot / CoIP / pull-down 的条带复制、拼接、跨图复用检测，**内参跨图复用**这一生物论文头号雷区专项检查（模板匹配 + 图内重复块初筛 + 逐命中目视复核）
- **生物学实验专项清单**：Western blot、琼脂糖凝胶、RT-qPCR、CFU 菌落计数、RNA-seq/蛋白组学、HPLC-MS、表型照片、Y2H/split-LUC、显微照片，逐类列出必查项
- **数值一致性**：源数据 Excel 与发表图逐项对账、统计复算（mean/SD/95CI/t 检验）、发表图散点像素级识别逐行比对
- **组学复核**：DEG/DEP 计数、Venn 集合运算、热图声称复现
- **色谱/质谱轨迹**：复制粘贴铁证检测（非零完全相同片段、基线噪声独立性）
- **元数据取证**：Office docProps 时间线、公式派生 vs 手填值

## 特色

- **判定分级对齐 ORI/COPE 学术不端定义**：🔴 红线（fabrication/falsification 铁证）/ 🟠 存疑 / 🟡 合规瑕疵（honest error）/ 🟢 通过（带覆盖率量化），不冤枉真实数据
- **强制执行的专业报告模板**：审查范围矩阵（每个检查项一行：模块/方法/数据基础/判定）、红线清单、未覆盖范围声明
- **统计取证方法族**：GRIM / GRIMMER / SPRITE / statcheck 式 p 值复算 / 末位数字分析（附适用条件）
- 内置**假阳性清单**（凝胶边缘、marker 重复上样、CFU 离散计数重复、色谱共同峰、饱和条带）
- 生物学实验专项清单：Western blot（含**内参跨图复用**头号雷区）、琼脂糖凝胶、RT-qPCR、CFU、RNA-seq/蛋白组学、HPLC-MS、表型照片、Y2H/split-LUC、显微照片
- 并行化编排建议（图像/数值/专项三路子任务）

## 使用

将 `SKILL.md` 放入助手的技能目录（如 `~/.kimi-code/skills/sci-audit/`），然后说"审查这篇论文的数据真实性"即可触发。
